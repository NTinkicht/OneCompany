# Changelog

## 0.1.0-foundation — 2026-09-12

Initial OneCompany operating system foundation:

- GitHub-source-of-truth constitution;
- Work Unit, single-stream lease, failover, exact-head review and expected-head merge model;
- machine-readable config, actors, roles, budget, queue, state, and schemas;
- zero-extra-spend safe defaults;
- dependency-free validation, diagnostics, routing, lease, simulation, bootstrap, and reconciliation tooling;
- worker onboarding/adapters for common AI environments;
- GitHub issue/PR templates and validation workflow;
- security, migration, incident, no-idle, observability, simulation, and Tabibi-derived lessons.

Licensing is intentionally left as a human governance decision before public open-source release.
