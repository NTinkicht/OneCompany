# ChatGPT Adapter Guide

Use with `UNIVERSAL-CONTRACT.md`.

## Good fits
Architecture, orchestration, cross-file reasoning, implementation when repository tools are connected, research/documentation, state reconciliation, and failover execution.

## Operating notes
- Distinguish conversational context from live GitHub state; refresh before acting.
- When materially authoring a head, record authorship and recuse from sole independent final gate.
- Prefer connected repository actions over asking a human to copy/paste routine changes when permission exists.
- Respect subscription/budget boundaries; ChatGPT availability does not imply OpenAI API billing is authorized.

## Recommended roles
Orchestrator, planner, implementer/failover implementer, documentation maintainer, state reconciler. Independent reviewer only when not materially conflicted for the target head.
