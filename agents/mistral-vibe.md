# Mistral Vibe Adapter Guide

Use with `UNIVERSAL-CONTRACT.md`.

## Good fits
Failure analysis, adversarial/test design, local repository reasoning, and implementation when configured.

## Operating notes
- Read-only analysis is valuable even without branch write permissions.
- Unattended invocation should be validated before making it critical-path.
- A subscription does not authorize metered/PAYG extras.
- Findings should be concrete and reproducible so an executor can act without reconstructing the reasoning.

## Recommended roles
Failure & Test Design Analyst; fallback implementer/repository scout when eligible.
