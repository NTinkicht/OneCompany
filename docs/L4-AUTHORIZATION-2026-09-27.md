# OneCompany L4 authorization — 2026-09-27

The repository owner explicitly authorizes **L4 — Continuous Company** engineering autonomy for the OneCompany source repository.

This promotion authorizes the governed continuous engineering loop to:
- select dependency-ready Work Units without a new human prompt;
- acquire/repair canonical implementation streams and leases;
- implement bounded code, tests and documentation;
- remediate deterministic CI failures;
- obtain independent non-author exact-head/exact-base review;
- merge mechanically when every configured gate passes;
- reconcile the portfolio after merge and immediately select newly ready work;
- perform no-idle failover and continuous scheduled/event-driven supervision.

The promotion does **not** weaken any existing control:
- exact-head/exact-base review and expected-head merge remain mandatory;
- all configured Medium-or-higher findings must be reconciled before merge;
- budget remains zero-extra-spend with no paid fallback, overage or new vendor;
- credentials/secrets cannot be expanded autonomously;
- destructive production operations, sensitive publication, constitutional/control-plane relaxation, and other configured human-only decisions remain human-only;
- emergency stop remains sovereign;
- one canonical implementation stream per Work Unit remains mandatory.

This authorization is prospective. Historical L1/B1 evidence remains valid as historical evidence and is not rewritten.
