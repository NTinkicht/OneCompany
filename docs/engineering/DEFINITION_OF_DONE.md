# Definition of Done

DONE means evidence-backed completion, not code committed.

A Work Unit is DONE only when: all scoped approved requirements and acceptance criteria are satisfied; traceability has no blocking orphan; required risk treatments are implemented and verified; required test families pass; coverage/mutation/baseline rules pass; architecture fitness functions pass; static quality checks pass; security and non-functional gates pass as required; documentation and operational artifacts are synchronized; migrations and rollback are verified when applicable; no blocking waiver is expired; independent non-author review passes the exact current SHA; and release evidence is stored or linked.

If the PR head changes after a merge-ready review, the exact-head gate is stale until re-established.
