# Observability and Reliability Standard

Observable systems provide enough evidence to diagnose whether requirements are being met in operation.

Operationally significant changes declare useful logs, metrics, traces/events, health signals, alerts and ownership while avoiding sensitive-data leakage. Reliability targets should be measurable where relevant.

High-risk changes include failure-mode testing, timeout/retry/idempotency behaviour, recovery and rollback evidence. Observability is verified during release rather than assumed because instrumentation code exists.
