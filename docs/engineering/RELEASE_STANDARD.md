# Release and Operational Readiness Standard

A merge is not automatically a successful release.

Production-oriented releases require artifact-to-SHA traceability, deployment preconditions, configuration/secrets expectations, migration strategy, rollback strategy, health/smoke verification, observability, alert ownership and post-release verification appropriate to risk.

High/critical-risk releases use staged rollout or equivalent blast-radius reduction where technically appropriate. Failed rollout evidence is retained and converted into corrective actions.
