# Security Engineering Standard

Security is designed and verified throughout the lifecycle. Use threat/risk analysis to select controls; use OWASP ASVS requirements where applicable to web/application security.

OneCompany expects least privilege, explicit trust boundaries, secure defaults, secret isolation, input/output validation at trust boundaries, authorization testing, dependency/security scanning and auditable sensitive actions as applicable.

Critical security/privacy findings block merge unless an explicit human-governed exception process permits otherwise. Autonomous agents cannot silently accept critical residual security/privacy risk.
