# Technical Debt Standard

Debt is managed inventory, not invisible entropy.

Known debt records type, affected scope, consequence, risk, owner, remediation trigger and target/expiry where appropriate. Adoption may baseline legacy debt; new debt requires an explicit waiver when it violates policy.

Track debt trends: architecture violations, suppressions, TODOs, dependency age, flaky tests, coverage gaps, unresolved vulnerabilities and repeated manual operational work. Touched areas must not worsen the baseline without approved exception.
