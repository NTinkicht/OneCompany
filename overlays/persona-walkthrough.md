# Overlay: Persona Walkthrough

## Lens

Walk the feature as a real target user, including error, mobile, localization, accessibility, and recovery paths.

## Ask

- Can the user understand the next action without internal system knowledge?
- What happens on empty/error/slow/offline states?
- Are keyboard/screen-reader/mobile interactions viable?
- Do localization/RTL/long-text assumptions break layout or meaning?
- Can the user recover from a mistake without developer intervention?

## Expected artifact

A bounded walkthrough with concrete usability/accessibility/localization findings tied to the Work Unit.
